# 来做吧 LetsDo

> 一个帮你「今天吃什么、今天动一动」的微信小程序：随机配餐 + 菜谱库 + 运动库 + 热量管理。
>
> 当前版本：**1.0.0**

## 项目简介

「来做吧 LetsDo」面向想好好吃饭、又想兼顾健康的普通用户。核心解决两件事：

1. **吃什么** —— 不想做饭时，按热量区间或完全随机一键搭配 2~4 道家常菜，自动算出整套菜单的热量、三大营养素与预估成本。
2. **动多少** —— 录入身高体重年龄算出每日基础代谢，记录今日摄入/消耗热量，按热量差额推荐适合的运动与时长。

## 功能一览

| 模块 | 功能 |
| --- | --- |
| 🎲 随机 | 热量限定随机（双滑块设定目标热量区间 + 忌口筛选）、完全随机、随机运动 |
| 📖 菜单库 | 菜名搜索、按食材筛选、54 道菜谱卡片列表 |
| 📖 菜谱详情 | 食材配比清单、整套营养汇总、**整套菜谱计算过程**（可展开）、视频号教程 |
| 🏃 运动库 | 按类别（有氧/力量/柔韧/球类/日常）浏览 25 项运动 |
| 🏃 运动详情 | 运动好处、每分钟与 30 分钟热量消耗、**消耗计算过程**、运动要点 |
| 👤 我的 | 身体数据（身高/体重/年龄/性别）→ 基础代谢 BMR |
| 👤 我的 | 记录今日摄入热量、今日消耗热量（不含新陈代谢），当天首次录入各 +1 积分 |
| 👤 我的 | 今日热量差额（摄入 − 基础代谢）＋运动推荐（建议分钟数 / 消耗热量 / 计算过程） |
| 👤 我的 | 微信头像昵称、每日打卡、打卡日历（可翻月、本月/本年统计）、积分排行榜、暗色模式 |
| 🏅 排行榜 | 积分排行榜（可关闭展示、退出排行） |

## 技术栈

- **框架**：uni-app（Vue 3 + `<script setup>`），编译到微信小程序
- **UI 组件库**：Wot Design Uni（`wd-button` / `wd-slider` / `wd-popup` / `wd-switch` / `wd-loading`）
- **后端**：微信云开发（云函数 + 云数据库 + 云存储），前端不直连数据库，全部走云函数
- **样式**：SCSS，主题变量统一放在全局，支持暗色模式

## 本地开发与构建

```bash
npm install

# 开发模式（产物 dist/dev/mp-weixin，支持热更新）
npm run dev:mp-weixin

# 生产构建（产物 dist/build/mp-weixin，供提交审核）
npm run build:mp-weixin
```

> 微信开发者工具默认加载 `dist/build/mp-weixin`（见 `project.config.json`）。如果工具加载的是 `dist/dev/mp-weixin`，改完代码后两个目录都要重新编译一次。

## 部署清单

首次或每次修改云函数后，都需要在微信开发者工具中操作：

1. 右键 `cloudfunctions/` 下被修改的云函数 → **上传并部署：云端安装依赖**。
   当前共 7 个：`generateMenu`、`recipeService`、`exerciseService`、`healthService`、`userService`、`doCheckin`、`getPointRank`。
2. 在「云开发控制台 → 数据库」确认集合已创建：`ingredient`、`recipe`、`exercise`、`user_profile`、`user_checkin`。
3. 开发者工具中「清缓存 → 全部清除」后重新编译。

## 更新日志

### 1.0.0（首个正式版本）

**新增**

- 随机配餐：热量限定随机（目标热量区间 + 忌口筛选）与完全随机两种模式。
- 菜单库：菜名搜索、按食材筛选，浏览全部菜谱。
- 菜谱详情：食材配比、整套营养汇总，并提供可展开的「整套菜谱计算过程」。
- 运动库：25 项运动的分类浏览，详情页展示运动好处与热量消耗。
- 我的：身体数据录入（身高/体重/年龄/性别）并实时计算每日基础代谢（BMR）。
- 我的：记录今日摄入热量、今日消耗热量（不含新陈代谢），当天首次录入各 +1 积分。
- 我的：今日热量差额卡片，按差额推荐运动（建议时长 + 消耗热量 + 计算过程）。
- 我的：每日打卡、打卡日历、积分排行榜、暗色模式。
- 随机页新增「随机运动」模式，一键随机推荐一项运动。

**优化**

- 底部导航由 3 个标签扩展为 4 个（随机 / 菜单库 / 运动库 / 我的）。
- 随机页三种模式统一了卡片高度与按钮位置，切换不再错位。
- 食材与菜谱占位图按类别区分（青菜 🥬 / 肉类 🥩 / 水产 🐟 / 蛋 🥚 / 菌菇 🍄 / 主食 🍚 等）。
